# Value Points & Answer Lengths (CBSE Class 10)

"Value points" are the marking-scheme bullets a human examiner would tick off — they must accompany **every** generated item, of every format, so the item is gradable.

## Word limits for answers, by marks

| Marks | Expected answer length |
|---|---|
| 1 | 1–2 sentences |
| 2 | 30–40 words |
| 3 | 40–50 words |
| 5 | 80–120 words |
| 6 | 100–150 words |

(English long answers: 100–120 words regardless of 5 or 6 marks.)

## Value point count & structure, by subject and marks

Override for **MCQ** and **fill-in-the-blank** regardless of marks or subject: exactly **1 value point** (MCQ: the reason the correct option is right; fill-blank: the correct answer itself, 1–3 words for science / 1–2 words for English). No catch-all phrase on these.

For short-answer and long-answer items, use this table:

### Science (max 15 words per value point; use formulas; include units)

| Marks | VP count | Structure |
|---|---|---|
| 1 | 1 | Single factual answer, term, or balanced equation — 1 mark |
| 2 | 2–4 | Each VP = ½ mark. Definition + example/application + formula if applicable |
| 3 | 3–6 | Each VP = ½ or 1 mark. Explanation + example + conclusion |
| 5 | 5–10 | Multi-part. Each VP = ½ or 1 mark. Theory + numerical + diagram descriptions |

Additional Science VP structure rules:

- **Numerical problems — break into step marks:** formula [½] → substitution [½] → calculation [½] → final answer with units [½]. Tag each VP with its mark weight ([½] or [1]).
- **Definitions:** formal definition + example/application.
- **Experiments:** procedure steps → observation → conclusion.
- State formulas/laws where applicable (e.g. F = ma, V = IR) — they must be correct, and chemical equations balanced.
- Include units in ALL numerical value points (e.g. 5 Ω, 10 m/s²) — missing units = missing marks.

### English (max 12 words per value point; textual evidence; interpretation allowed)

| Marks | VP count | Structure |
|---|---|---|
| 1 | 2–3 | (Any One Value Point) — single word or short phrase from text |
| 2 | 3 | (Any Two Value Points) — marks split 1+1 |
| 3 | 3–4 | Content – 2 marks (Any Two Value Points); Expression – 1 mark (coherence, cohesion, style) |
| 5 | 4–5 | Content – 3 marks (Any Three Value Points); Expression – 1.5 marks; Accuracy – 0.5 mark (spelling/punctuation/grammar) |
| 6 | 5–6 | Content – 3 marks (Any Three Value Points); Expression – 2 marks; Accuracy – 1 mark |

## Universal value-point rules

- Every **short-answer and long-answer** value point list ends with: **"(Any other relevant point to be accepted)"**. (Not on MCQ/fill-blank — those have exactly one VP.)
- Value points must be factually correct, cover everything needed for full marks, and be clear enough for objective (not subjective) marking.
- Write value points in simple, student-friendly language — the target audience is 14–16 year old CBSE Class 10 students, non-native English speakers, elementary-to-intermediate comprehension.
- Science: use "/" only for same-thing-different-notation (e.g. "Plaster of Paris / Calcium sulphate hemihydrate"), never for genuine alternatives.
- English: use "/" for genuine alternative phrasings within one value point (e.g. "compassionate/understanding/kind").
