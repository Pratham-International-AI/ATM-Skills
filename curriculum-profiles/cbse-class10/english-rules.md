# English Literature Item Generation Rules (CBSE Class 10)

Role while generating: a CBSE Class 10 English curriculum expert setting a Board-exam-standard question paper.

## Global rules for every English item

- **Literature-based only** — no grammar, unseen reading comprehension, or unseen passages. Draw only from the prescribed textbook/supplementary reader content supplied as source material.
- Use terminology **exactly** as it appears in the chapter — no synonyms (e.g. if the text says "bodhi tree", never write "peepal").
- Refer to the source by its actual genre in the question ("from the story", "from the poem", "from the lesson", "from the play") — never the generic word "text".
- Keep questions concise and direct — no extra clauses/hints that give away the answer.
- Every question in a batch must be **unique in intent** — no two questions testing the same idea.

## MCQ-specific

- All four options equal in word length and style — if the answer is one word, all distractors are one word; the correct answer must never stand out as longer or more "textual".
- All options (including distractors) must sound plausibly like they belong to the chapter — no generic/made-up-sounding distractors.
- Short options are good; single-word options are fine for Remembering-level questions.
- Good: `Devastated` / `Overjoyed` / `Indifferent` / `Confused`. Bad: one option is a full descriptive sentence while others are single words.
- Exactly 1 value point: why the correct answer is right.

## Fill-in-the-blank–specific

- Whole sentence ≤10 words — short and direct.
- The sentence itself must be sourced from the chapter.
- Answer is 1–2 words (a name, term, or number) sourced from the chapter.
- Blank a keyword (name/term/number/place), never a trivial word.
- Exactly 1 value point: the correct answer only, no variations needed.

## Short-answer–specific

- Length per `value-points.md` (e.g. 40–50 words for 3 marks).
- Answerable from a single passage/section — never combine content from separate passages or chapters into one question.
- Difficulty must match the marks — a 2-mark question shouldn't feel like a 3-mark one.

## Long-answer–specific

- Length per `value-points.md` (typically 100–120 words).
- Single theme/character/event — not multiple topics combined; must not overlap with any short-answer question in the same batch.
- For cross-text/comparison questions explicitly requested: require at least one value point from each text, and note this in the value points list.

## Value point phrasing (English-specific)

- Each value point is a short phrase, 1–8 words (e.g. "Devastated", "compassionate/understanding/kind", "faith in god — wasn't disheartened").
- Value points are **suggested wording**, not the only acceptable answer — students may express the idea in their own words at marking time; the value point exists to define the *idea*, not the exact sentence.
